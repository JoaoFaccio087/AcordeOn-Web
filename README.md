# AcordeOn — Web

Site público do **AcordeOn**, aplicativo para organizar cifras e repertórios no celular e no tablet.

Este repositório guarda apenas as páginas do site. **O código do aplicativo é privado.**

## Páginas

| Página | Endereço |
|---|---|
| Apresentação | https://joaofaccio087.github.io/AcordeOn-Web/ |
| Política de privacidade | https://joaofaccio087.github.io/AcordeOn-Web/privacidade.html |

## Arquivos

- `index.html` — página de apresentação do app
- `privacidade.html` — política de privacidade (exigida pelas lojas de aplicativos)
- `icone.png` — ícone do app usado nas páginas

## Publicação

As páginas são publicadas pelo **GitHub Pages**, a partir do branch `main`, na raiz do repositório. Qualquer alteração enviada para o `main` entra no ar em poucos minutos.
